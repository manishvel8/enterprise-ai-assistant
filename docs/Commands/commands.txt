### 1) Neo4j — why + how to use it here

**Why Neo4j (not instead of Qdrant):**  
Qdrant finds *similar text chunks*. Neo4j stores *entities and relationships* (Person → Organization, Document → Chunk, topics, decisions). That’s GraphRAG: better answers for “who / related to / connected to”.

Your DB already has ~87 nodes (`Document`, `Chunk`, `Person`, `Organization`, `Topic`, …) and relationships like `MENTIONS`, `BELONGS_TO_TOPIC`.

**Fix your query** — don’t put `{Document, Chunk…}` after `LIMIT`. Use:

```cypher
// Everything (small demo)
MATCH (n) RETURN n LIMIT 50

// Just your resume document
MATCH (d:Document {file_name: 'Resume_BhanuTeja_DS.pdf'})
RETURN d

// Document → chunks
MATCH (c:Chunk)-[:BELONGS_TO|PART_OF|IN_DOCUMENT*0..1]-(d:Document)
WHERE d.file_name CONTAINS 'Resume' OR c.document_id = 'doc_da15a786238a'
RETURN c, d LIMIT 25

// Safer generic: all Document + Chunk + Person
MATCH (n)
WHERE n:Document OR n:Chunk OR n:Person OR n:Organization
RETURN n LIMIT 50

// Mentions / links from a chunk
MATCH (c:Chunk)-[r]->(e)
WHERE c.document_id = 'doc_da15a786238a'
RETURN c, r, e LIMIT 50

// Person connected to orgs/topics
MATCH (p:Person)-[r]-(x)
RETURN p, r, x LIMIT 50
```

## How `router_node` decides (the important part)

### Layer 1 — Heuristics (fast, no LLM, ~0 ms)

```72:88:langgraph-agent/app/agents/router.py
def _heuristic_route(query: str) -> tuple[str, str] | tuple[None, str]:
    if _FORCE_HUMAN.search(query):
        return ("needs_human", "Should I search your uploaded documents, or look this up on the live web?")
    if _GREET_ONLY.match(query.strip()):
        return "web_search", ""
    if _DOC_HINTS.search(query) and not _WEB_HINTS.search(query):
        return "rag", ""
    if _WEB_HINTS.search(query) and not _DOC_HINTS.search(query):
        return "web_search", ""
    return None, ""  # unclear → LLM
```

| Regex | Meaning | Example → route |
|--------|---------|------------------|
| `_FORCE_HUMAN` | Explicit “docs **or** web / internet” | “Should I use my documents or the internet…?” → **needs_human** |
| `_DOC_HINTS` only | resume, CV, skill, experience, pdf… | “Neha Pukale skills?” → **rag** |
| `_WEB_HINTS` only | latest, 2026, news, today, stock… | “Latest AI trends in 2026?” → **web_search** |
| Both / neither | Ambiguous | Fall through to LLM |
| Greeting only | hi/hello | **web_search** (general) |

**Why heuristics first?** Cheaper, deterministic, fixes LLM misroutes (we saw that on the enterprise app too). Trace shows `route=rag (heuristic)`.

### Layer 2 — LLM structured classifier (only if heuristics return `None`)

- Prompt lists exactly 3 routes; `needs_human` is **last resort**
- Response forced into Pydantic `RouteSchema` (`route`, `reasoning`, `human_question`)
- Invalid route string → forced to `"rag"`
- LLM failure → fallback `"rag"`


### What is MCP? (short)

**MCP = Model Context Protocol** — a standard “USB plug” for AI tools.

- **Not** a model, not LangGraph, not Qdrant  
- A **client ↔ server protocol** so any AI host can **discover** and **call** tools  
- **Server** = owns tools · **Client** = lists/calls them · **Transport** = usually stdio (subprocess)
